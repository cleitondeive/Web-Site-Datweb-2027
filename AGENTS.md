# Orientações do projeto Datweb

- Este é um site estático em HTML, CSS e JavaScript. Não migre de framework nem adicione dependências sem necessidade do pedido.
- Use `npm run dev` para iniciar a prévia em `http://127.0.0.1:3000` e `npm test` para verificar alterações.
- Preserve a identidade clara em azul, a legibilidade e o layout responsivo.
- Mantenha os cards sem inclinação ou movimento agressivo ao passar o mouse. O carrossel principal deve continuar automático, com controles de pausa e respeito à preferência de reduzir animações.
- Os formulários preparam uma mensagem para o WhatsApp (65) 3029-9800. O envio é concluído pelo visitante; nunca exiba confirmação fictícia de entrega e nunca envie contatos de teste.
- O aviso de cookies está temporariamente oculto por solicitação do usuário. Não simule aceite nem altere preferências de consentimento.
- Não adicione credenciais, backups locais, capturas de trabalho ou arquivos de outros projetos ao Git.
- Verifique links e recursos locais, rode os testes e confira as telas afetadas antes de concluir uma alteração visual.
